## Informe resultados de tratamiento de imagen
- Objetivo: Diseñar y escribir un documento que contenga la solución a un ejercicio de reconocimiento y tratamiento de imagen.

- Solución: Documentación y analisis del codigo trabajado en las sesiones sincronicas de Percepcion Computacional, con varios ajustes personalizados para la detección de objetos y descarga de reporte con nuevos datos en csv.
